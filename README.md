# PYTHON PRO | SHARKCODERS

Exercícios resolvidos do curso Python PRO, organizados por módulo e por aula.

## Estrutura

```
Modulo_I/   Aula_01 a Aula_10
Modulo_II/  Aula_11 a Aula_20
```

Cada pasta contém os ficheiros .py da aula (exemplos, exercícios, desafio e exercícios extra) e os ficheiros de dados necessários (.txt, .csv, .json, .db).

| Aula | Tema |
|---|---|
| 01 | Introdução à Programação e Lógica |
| 02 | Variáveis, Tipos de Dados e Operadores |
| 03 | Estruturas Condicionais |
| 04 | Bibliotecas e Ciclo while |
| 05 | Ciclo for e range() |
| 06 | Formatação de Resultados e Tratamento de Erros |
| 07 | Listas |
| 08 | Percorrer Listas e List Comprehensions |
| 09 | Funções |
| 10 | Projeto Intermédio |
| 11 | Dicionários |
| 12 | Ficheiros de Texto |
| 13 | Percorrer Ficheiros e Registos |
| 14 | Ficheiros CSV |
| 15 | JSON e APIs |
| 16 | Interfaces Gráficas com Tkinter (I) |
| 17 | Interfaces Gráficas com Tkinter (II) |
| 18 | Bases de Dados com SQLite |
| 19 | CRUD |
| 20 | Projeto Final |

## Requisitos

- Python 3.10 ou superior
- Aula 15: `pip install requests`
- Aulas 18 e 19: DB Browser for SQLite (opcional, para visualizar as bases de dados)

Os exercícios que usam ficheiros de dados devem ser executados dentro da pasta da respetiva aula.
